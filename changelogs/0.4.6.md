## [0.4.6] - 2026-11-03

### 亮点

「跨越」开发周期的首个 alpha：只收敛 v1 文档与决策，**不含功能代码**。

### 改进

- 记忆系统对外名称定为 **APEMS**（Aris Project Engram Memory System）；命令、配置项与包名不变，
  仍叫 `memory`。
- 决策模型不再用主模型兜底（逐条判断成本太高）：只保留专用决策模型，失败按概率 / 规则降级；
  消息密集时先攒一小批再判一次，减少调用次数。
- 记忆可以自然「变重要」：中期记忆在 30 天内被真实检索命中覆盖 ≥3 个不同自然日就晋升长期；
  随机回忆不计入晋升。
- 真实命中与随机回忆共用 384 的自动加成额度，避免同一份「被检索到」的证据被重复计分。
- 换 embedding 模型走影子表全量重建；记忆库不再区分热表 / 冷表，一个库一套表。
- 配置档边界调整：`serve.toml` / `webui.toml` 不随档，切档不会改变监听地址（GUI 因此不写死端口）。
- 插件系统整体推迟到 v1.1，v1.0 不做也不预留接口。

### 修复

- 修正 v1 施工文档里失效的章节引用，以及 `private` 语义、`importance` 与预设、compact 与记忆摘要模板
  两套并存、共享加成额度等自相矛盾之处。

### 升级注意

- 这是 alpha 快照，只用于固定 v1 决策；没有数据库与配置迁移。
