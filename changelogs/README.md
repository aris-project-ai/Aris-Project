# 变更记录（changelogs/）

每个发布版本一个文件：`changelogs/<版本>.md`（与 tag 的数字一致，如 `v0.4.4` → `0.4.4.md`）。
未发布的改动顺手追加到 `unreleased.md`，发版时把它移动到对应版本文件。

## 格式

```markdown
# <版本>（YYYY-MM-DD）

## 新增
- ...

## 修复
- ...

## 变更 / 不兼容
- ...（不兼容项写清迁移方式）
```

- 面向**使用者**：写可见变化与操作影响，不写内部重构细节。
- 没有内容的分类直接省略，不写「无」。
- 与 tag 渠道无关（beta / 正式 / alpha 共用同一条数字线，只用数字命名文件）。
